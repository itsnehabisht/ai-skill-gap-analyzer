# AI Skill Gap Analyzer

An ML-based application that analyzes a candidate's skills and predicts job readiness.

## Current Status

Day 1 and Day 2 completed.

## Technologies

- Python
- Pandas
- Scikit-learn
- Random Forest
- FastAPI
- Next.js
- TypeScript

## Machine Learning

The current prototype uses a Random Forest Regressor to predict job readiness.

Current prototype evaluation:

- MAE: 3.46
- R²: 0.8644

> Note: The current training dataset is synthetic and these metrics should not be interpreted as real-world performance.
